# Curso Base de Datos 2026

## Configuración

Instalación de pgbot

```bash
npm i -g @pgbot/cli
```

Verificar la instalación

```bash
pgbot --version
```

Conecta pgbot a tu PostgreSQL:

```bash
pgbot inspect "postgres://usuario:password@localhost:5432/mi_base_de_datos"
```
